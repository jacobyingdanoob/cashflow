# Cashflow 1.2.0

This release brings Cashflow to Mac and introduces the game to first-time players across Mac, Windows and the browser.

## First-launch introduction

**Welcome to Cashflow** explains the financial board game's goal: build passive income above expenses to escape the Rat Race, then pursue your dream or extra-income target in a full game. It introduces this edition's additions to the original board-game mechanics: persistent markets, flexible trading with fees and tax, lending limits, equal starting finances with different NPC personalities, guided accounting and tutorials, autosaves, transaction history and coaching.

The introduction appears once per local profile before the role reveal and tutorials. It can be reopened from **How to play → About Cashflow & this edition**. Reading it pauses NPC play, preserves the current match and works with keyboard navigation and small screens. Closing it acknowledges the introduction; clearing local application or site data makes it appear again.

## Mac application

- A universal **Cashflow.app** includes both Apple Silicon and Intel binaries, bundled fonts and the offline game runtime.
- Native application, editing and window menus provide standard Mac shortcuts. Saves live in `~/Library/Application Support/Cashflow`.
- The application is ad-hoc signed for local execution, without an Apple Developer ID signature or notarization. macOS may require approval to open it.
- The release workflow builds and tests the packaged archive on a GitHub-hosted Mac before uploading it.

- [Browser ZIP](https://github.com/jacobyingdanoob/cashflow/releases/download/v1.2.0/Cashflow-1.2.0-web.zip) — extract and run `node serve.cjs` or use a static HTTP host. See the [browser guide](../web.md).

`SHA256SUMS-macos.txt` verifies the Mac download; `SHA256SUMS.txt` verifies the Windows and browser downloads. Game rules are unchanged from v1.1.0. Existing saves remain supported and the first-launch introduction is stored independently of each match.
